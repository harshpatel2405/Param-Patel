C Language 
----------
It was developed in 1972 by Dennis Ritchie 

Linux is based on C 

C is known as mother of all languages 
Dennis Ritchie is known as father of C Language

C is a compiled Language

<====================================================================>
C Language is divided into sections

1. Header section
2. Definition Section 
3. Global Decalration  Section 
4. Main Function Section 
5. User Defined Function Section 
<=====================================================================>
1. Header Section 
-> It will have header files 
-> Header Files contains in-built functions
    
    #include<stdio.h>

    #       -> pre processor (tells the compiler to check the thing is available or not)
    include -> folder name where all the header files are present 
    <>      -> angular brackets (this will search only in include folder)
    stdio   -> standard input output header file (printf , scanf) (function calling)

4. Main Function Section 
-> It is starting and ending point of execution of a program
    
    main is the logical start of a program 

    // function definition 
    returnType function_name(args )
    {
        // logic 
    }

    int main()
    {
        return 0;
    }
<==============================================================================>
