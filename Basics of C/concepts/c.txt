===============================
        C LANGUAGE NOTES
===============================

INTRODUCTION
------------
- C language was developed in 1972 by Dennis Ritchie
- Linux is based on C
- C is known as the "Mother of all Languages"
- Dennis Ritchie is known as the Father of C Language
- C is a compiled language


========================================
STRUCTURE OF A C PROGRAM
========================================

C Language is divided into the following sections:

1. Header Section
2. Definition Section
3. Global Declaration Section
4. Main Function Section
5. User Defined Function Section


========================================
1. HEADER SECTION
========================================

- Contains header files
- Header files include in-built functions

Example:
#include <stdio.h>

Explanation:
#        -> Preprocessor (checks before compilation)
include  -> Includes header file
<>       -> Searches inside system include folder
stdio.h  -> Standard Input Output (printf, scanf)


========================================
4. MAIN FUNCTION SECTION
========================================

- Starting and ending point of program execution
- Every program must have main()

General Syntax:

returnType function_name(arguments)
{
    // logic
}

Example:

int main()
{
    return 0;
}


========================================
COMMENTS IN C
========================================

- Comments are ignored by the compiler
- Used for user understanding

1. Single Line Comment:
   Symbol: //
   Example:
   // This is a comment

2. Multi Line Comment:
   Symbols: /* */

   Example:
   /*
       This is a
       multi-line comment
   */

Standard Format:
   /*
       Name : __________
       Objective : __________
       DOC : dd_mm_yyyy
   */


========================================
BASIC PROGRAM
========================================

Task: Print Hello World

#include <stdio.h>

int main()
{
    printf("Hello World");
    return 0;
}


========================================
DATA TYPES IN C
========================================

Types of Data Types:

1. Primitive (Inbuilt)
   int, float, char, double, short, long, signed, unsigned

2. Derived (Based on Primitive)
   array, pointer, function

3. User Defined (Custom)
   structure, union, enum


========================================
DATA TYPE SIZE AND RANGE
========================================

***** Turbo C *****

int            -> 2 bytes   -> -32768 to 32767
char           -> 1 byte    -> -128 to 127
float          -> 4 bytes   -> 3.4 × 10^-38 to 3.4 × 10^38
void           -> 0 bytes   -> no range
long int       -> 4 bytes   -> -2,147,483,648 to 2,147,483,647
double         -> 8 bytes   -> 1.7 × 10^-308 to 1.7 × 10^308
long double    -> 10 bytes  -> 3.4 × 10^-4932 to 1.1 × 10^4932


***** Modern Compilers *****

int            -> 4 bytes   -> -2,147,483,648 to 2,147,483,647
char           -> 1 byte    -> -128 to 127
float          -> 4 bytes   -> 1.2 × 10^-38 to 3.4 × 10^38
void           -> 0 bytes   -> no range
long int       -> 8 bytes   -> -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807
double         -> 8 bytes   -> 2.3 × 10^-308 to 1.7 × 10^308
long double    -> 16 bytes  -> 3.4 × 10^-4932 to 1.1 × 10^4932
