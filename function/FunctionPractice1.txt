--------------------------------
1) WITHOUT RETURN, WITHOUT ARGUMENT
--------------------------------
1. Print your name.  
2. Print "Hello, World!" 10 times.  
3. Print first 10 natural numbers.  
4. Display multiplication table of 5.  
5. Print all even numbers between 1 and 50.  
6. Print sum of first 100 natural numbers.  
7. Print squares of numbers from 1 to 10.  

--------------------------------
2) WITHOUT RETURN, WITH ARGUMENT
--------------------------------

1. Accept a number and print its square.  
2. Accept a number and print whether it is even or odd.  
3. Accept two numbers and print their sum.  
4. Accept two numbers and print their product.  
5. Accept a number and display its multiplication table.  
6. Accept two numbers and print the greater one.  

--------------------------------
3) WITH RETURN, WITHOUT ARGUMENT
--------------------------------

1. Return a fixed number (like 10).  
2. Return the current year (hardcoded).  
3. Return sum of first 50 natural numbers.  
4. Return the largest of three fixed numbers.  
5. Return factorial of 5.  
6. Generate and return a random number.  
7. Return area of a circle with fixed radius.  
8. Return whether a fixed number is palindrome or not.  
9. Return sum of squares of first 10 numbers.  
10. Return whether a fixed number is Armstrong number.

--------------------------------

1. Return square of a given number.  
2. Return cube of a given number.  
3. Return maximum of two numbers.  
4. Return minimum of two numbers.  
5. Return whether a number is prime.  
6. Return area of circle using radius.  
7. Return sum of digits of a number.  
8. Return length of a string.

5) COMBINED QUESTIONS
--------------------------------
1. Use one function to accept marks, another to calculate percentage, another to return grade, and finally display result.
